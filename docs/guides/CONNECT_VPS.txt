--------------------------------------------------------------------------------
1. HƯỚNG DẪN TRÊN WINDOWS (PowerShell)
--------------------------------------------------------------------------------

Bước 1.1: Cài đặt cloudflared CLI
  Mở PowerShell (Run as Administrator) và chạy:
    winget install Cloudflare.cloudflared
    # Hoặc qua Chocolatey:
    # choco install cloudflared

Bước 1.2: Cấu hình tự động ~/.ssh/config trên Windows
  Copy và dán toàn bộ đoạn sau vào PowerShell:

    $cfPath = (Get-Command cloudflared -ErrorAction SilentlyContinue).Source
    if (-not $cfPath) { $cfPath = "cloudflared.exe" }
    $sshDir = "$HOME\.ssh"
    if (!(Test-Path $sshDir)) { New-Item -ItemType Directory -Path $sshDir -Force | Out-Null }

    $configContent = @"
    # ==============================================================================
    # RIDEHUB VPS SSH CONFIGURATION (Windows)
    # ==============================================================================

    # 1. Kết nối qua Cloudflare Zero Trust (Bảo mật Keycloak OIDC)
    Host ridehub
        HostName ssh.phungvip.io.vn
        User phungvip
        IdentityFile ~/.ssh/google_compute_engine
        ProxyCommand "$cfPath" access ssh --hostname %h
        StrictHostKeyChecking no
        UserKnownHostsFile /dev/null

    # 2. Kết nối trực tiếp qua IP VPS (Dự phòng - Tốc độ nhanh)
    Host ridehub-direct
        HostName 136.85.105.222
        User phungvip
        IdentityFile ~/.ssh/google_compute_engine
        StrictHostKeyChecking no
        UserKnownHostsFile /dev/null
    "@

    Set-Content -Path "$HOME\.ssh\config" -Value $configContent -Encoding utf8
    Write-Host "✓ Đã ghi cấu hình vào: C:\Users\$env:USERNAME\.ssh\config" -ForegroundColor Green

Bước 1.3: Đăng nhập Cloudflare Zero Trust (Chạy 1 lần trên máy)
    cloudflared access login https://ssh.phungvip.io.vn
    -> Trình duyệt tự mở, đăng nhập tài khoản Keycloak:
       Username : admin.phungvip
       Password : <Xem trong file infra/vps-infra/.env (biến KC_PASS_ADMIN_PHUNGVIP)>

Bước 1.4: Kết nối SSH
    ssh ridehub          # Qua Cloudflare Zero Trust
    # hoặc
    ssh ridehub-direct   # Trực tiếp qua IP

  * Sử dụng trong VS Code:
    Nhấn Ctrl+Shift+P (hoặc F1) -> Gõ "Remote-SSH: Connect to Host..." -> Chọn "ridehub".

--------------------------------------------------------------------------------
2. HƯỚNG DẪN TRÊN LINUX (Arch Linux, Ubuntu, Debian, Fedora)
--------------------------------------------------------------------------------

Bước 2.1: Cài đặt cloudflared trên Linux
  - Trên Arch Linux:
      sudo pacman -S cloudflared
  - Trên Ubuntu / Debian:
      curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
      echo "deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/cloudflared.list
      sudo apt update && sudo apt install cloudflared
  - Trên Fedora / RHEL:
      sudo dnf install cloudflared

Bước 2.2: Cấu hình ~/.ssh/config trên Linux (Tối ưu tốc độ với ControlMaster)
  Mở terminal Linux và chạy đoạn lệnh sau:

    mkdir -p ~/.ssh/sockets && chmod 700 ~/.ssh

    cat << 'EOF' > ~/.ssh/config
    # ==============================================================================
    # RIDEHUB VPS SSH CONFIGURATION (Linux)
    # ==============================================================================

    # 1. Kết nối qua Cloudflare Zero Trust (Tăng tốc bằng ControlMaster Socket)
    Host ridehub
        HostName ssh.phungvip.io.vn
        User phungvip
        IdentityFile ~/.ssh/google_compute_engine
        ProxyCommand cloudflared access ssh --hostname %h
        StrictHostKeyChecking no
        UserKnownHostsFile /dev/null
        ControlMaster auto
        ControlPath ~/.ssh/sockets/%r@%h:%p
        ControlPersist 10m

    # 2. Kết nối trực tiếp qua IP VPS (Dự phòng)
    Host ridehub-direct
        HostName 136.85.105.222
        User phungvip
        IdentityFile ~/.ssh/google_compute_engine
        StrictHostKeyChecking no
        UserKnownHostsFile /dev/null
    EOF

    chmod 600 ~/.ssh/config

Bước 2.3: Phân quyền Private Key bắt buộc trên Linux
    chmod 600 ~/.ssh/google_compute_engine

Bước 2.4: Đăng nhập & Kết nối SSH trên Linux
    cloudflared access login https://ssh.phungvip.io.vn
    ssh ridehub

--------------------------------------------------------------------------------
3. MẸO DÙNG CHUNG SSH KEY KHI CHẠY DUAL-BOOT (Windows + Linux)
--------------------------------------------------------------------------------
  Nếu bạn cài song song Windows và Arch Linux trên cùng 1 máy:
  - File key gốc nằm ở Windows: /mnt/c/Users/<your_user>/.ssh/google_compute_engine
  - Trên Linux, KHÔNG ĐƯỢC symlink trực tiếp từ phân vùng NTFS vì NTFS không hỗ trợ
    quyền chmod 600 (Linux SSH sẽ báo lỗi: "Permissions are too open").
  - Cách làm chuẩn:
      cp /mnt/c/Users/<your_user>/.ssh/google_compute_engine ~/.ssh/google_compute_engine
      chmod 600 ~/.ssh/google_compute_engine

PHẦN II: DÀNH CHO DEVELOPER (DÙNG CLOUDFLARE WARP ĐỂ CODE LOCAL)
================================================================================
  Mô hình chuẩn Zero Trust: Dev KHÔNG CẦN SSH vào VPS!
  Dev chạy code trên laptop của mình, chỉ cần bật WARP để kết nối vào Database,
  Kafka, Redis, Consul trên VPS như đang ngồi chung mạng LAN.

--------------------------------------------------------------------------------
1. CÀI ĐẶT & KẾT NỐI WARP TRÊN WINDOWS
--------------------------------------------------------------------------------
Bước 1: Mở PowerShell cài đặt:
    winget install Cloudflare.WARP

Bước 2: Đăng ký vào Team RideHub (Chỉ làm 1 lần):
    warp-cli registration new appf4
    -> Trình duyệt tự mở, đăng nhập tài khoản Keycloak của bạn (hoặc OTP email).

Bước 3: Bật kết nối vào mạng nội bộ VPS:
    warp-cli connect

  Kiểm tra trạng thái:
    warp-cli status
    -> Báo "Status update: Connected" là thành công!

  Ngắt kết nối khi hết giờ làm:
    warp-cli disconnect

--------------------------------------------------------------------------------
2. CÀI ĐẶT & KẾT NỐI WARP TRÊN LINUX
--------------------------------------------------------------------------------
Bước 1: Cài đặt WARP CLI trên Linux:
  - Trên Arch Linux:
      yay -S cloudflare-warp-bin
  - Trên Ubuntu / Debian:
      sudo apt update && sudo apt install cloudflare-warp

Bước 2: Kích hoạt dịch vụ ngầm của WARP trên Linux:
    sudo systemctl enable --now warp-svc

Bước 3: Đăng ký thiết bị vào Team appf4:
    warp-cli registration new appf4
    -> Terminal hiển thị link đăng nhập (hoặc tự mở trình duyệt), dev đăng nhập Keycloak.

Bước 4: Bật kết nối mạng nội bộ:
    warp-cli connect
    warp-cli status

PHẦN III: XỬ LÝ SỰ CỐ THƯỜNG GẶP (TROUBLESHOOTING)
================================================================================

1. Lỗi: "Permission denied (publickey)"
   -> Nguyên nhân: Thiếu dòng `IdentityFile ~/.ssh/google_compute_engine` trong khối `Host ridehub`.
   -> Cách sửa: Bổ sung dòng IdentityFile vào file ~/.ssh/config.

2. Lỗi: "posix_spawnp: No such file or directory" trên Windows / VS Code
   -> Nguyên nhân: OpenSSH không tìm thấy file cloudflared.exe trong PATH.
   -> Cách sửa: Ghi đường dẫn tuyệt đối vào ProxyCommand:
      Ví dụ: ProxyCommand "C:\Program Files (x86)\cloudflared\cloudflared.exe" access ssh --hostname %h

3. Lỗi: "Permissions 0777 for google_compute_engine are too open" trên Linux
   -> Nguyên nhân: File key có quyền quá rộng hoặc đang nằm trên ổ đĩa NTFS của Windows.
   -> Cách sửa: Copy key vào ổ Linux:
      chmod 600 ~/.ssh/google_compute_engine

4. Lỗi: "unrecognized subcommand 'teams-enroll'" trên WARP CLI
   -> Các phiên bản WARP mới đã đổi cú pháp lệnh.
   -> Cách sửa: Dùng lệnh chuẩn mới:
      warp-cli registration new appf4
