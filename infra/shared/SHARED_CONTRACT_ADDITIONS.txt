I. RIDEHUB-CONTRACT (Schema & Contract Governance)
--------------------------------------------------------------------------------
1. Pact Contract Testing (Consumer-Driven Contracts)
   - Lưu trữ các file Pact contract (HTTP & Kafka Event) được sinh ra từ Consumer.
   - Thêm CI script chạy `pact-broker can-i-deploy` để chặn release nếu vỡ contract.
   - Tích hợp Message Pact cho Kafka events (kiểm thử payload giữa Producer và Consumer).

2. Semantic Linting (Thay thế validate-schemas.sh chỉ check syntax)
   - Tích hợp Spectral / Redocly CLI để lint toàn bộ OpenAPI & AsyncAPI theo style-guide 
     (bắt buộc HTTP status, mô tả error response, camelCase naming).

3. Breaking Change Detection (CI/CD)
   - Tích hợp `oasdiff` / `openapi-diff` trong GitHub Actions: tự động so sánh OpenAPI 
     spec mới với git tag trước đó, chặn PR nếu có breaking change (xóa field, đổi type).
   - Avro Schema Compatibility check: kiểm tra backward/forward compatibility của 
     `EventEnvelope.avsc` trước khi build JAR.


II. RIDEHUB-SHARED (Runtime Library cho Microservices)
--------------------------------------------------------------------------------
1. Feign Client Resilience & Fault Tolerance (Cực kỳ quan trọng)
   - Resilience4j Circuit Breaker: tự động ngắt mạch khi provider (ms_route, ms_user...) sập, 
     tránh treo thread pool làm sập dây chuyền (cascading failure).
   - Chuẩn hóa ConnectTimeout (2s) & ReadTimeout (5s) có thể cấu hình động qua Consul KV.
   - Retry policy với Exponential Backoff cho các API idempotent (GET).
   - Hỗ trợ Feign Fallback / FallbackFactory cơ bản.

2. Smart Feign ErrorDecoder (RFC 7807 Consumer-Side)
   - JHipster đã có ExceptionTranslator ở phía Provider để trả về JSON ProblemDetails.
   - Phía Consumer (Feign) đang bị ném generic `FeignException [400/500]`.
   - Cần: `RidehubFeignErrorDecoder` tự động parse ProblemDetails từ Provider thành 
     các Exception nghiệp vụ cụ thể ở Consumer (vd: SeatAlreadyLockedException, 
     ResourceNotFoundException, InvalidPromotionException).

3. Redis Utilities (Tận dụng Redisson có sẵn trong POM của JHipster)
   - Distributed Lock: Cung cấp annotation `@DistributedLock(key = "...", waitTime = ...)` 
     để các service (ms_booking, ms_route, ms_promotion) dùng chung cho nghiệp vụ 
     khóa ghế (seat lock), giữ chỗ, áp mã giảm giá mà không cần code chay `opsForValue().setIfAbsent`.
   - Redis Idempotency Manager: Helper kiểm tra trùng lặp request hoặc event qua Redis key + TTL.
   - Chuẩn hóa RedisTemplate serializer (GenericJackson2JsonRedisSerializer) tránh lỗi 
     lệch ObjectMapper khi cache DTO chung.

4. Distributed Tracing & Logging MDC Propagation (Observability)
   - Feign Interceptor: Tự động truyền W3C `traceparent` và `X-Correlation-Id` sang service đích.
   - Kafka Headers: Tự động inject/extract `traceId` vào Kafka Message Headers khi produce/consume.
   - SLF4J MDC Filter: Tự động nạp `traceId`, `spanId`, `userId` vào mọi dòng log đẩy về Loki, 
     giúp 1-click tra vết toàn bộ luồng gọi từ Gateway -> Booking -> Route -> Kafka trên Grafana.

5. Kafka Consumer Reliability & Dead Letter Topic (DLQ)
   - Dead Letter Topic (DLT): Tự động định tuyến message lỗi sau N lần retry sang `<topic>.DLT` 
     thay vì ném exception vô tận gây nghẽn Kafka partition (chống Poison Pill).
   - Actuator endpoint hoặc utility hỗ trợ replay các message lỗi trong DLT.

6. Pact Test Support Utilities (Testing Base)
   - Cung cấp Base Test Class & Mocking annotations cho Consumer viết Pact tests với Feign.
   - Cung cấp Provider Verification base class để service tự động verify endpoint với Pact Broker.


III. HẠ TẦNG BỔ TRỢ TRÊN VPS-INFRA ĐỂ PHỤC VỤ CÁC MỤC TRÊN
--------------------------------------------------------------------------------
1. Container `pactfoundation/pact-broker`: Quản lý, lưu trữ và hiển thị ma trận tương thích 
   Pact contracts giữa các service (route qua Cloudflared/Nginx: pact.phungvip.io.vn).
2. Container `grafana/tempo`: Nhận và lưu trữ Traces từ các microservice, hoàn thiện bộ 3 
   Logs (Loki) + Metrics (Prometheus) + Traces (Tempo) ngay trên Grafana.
